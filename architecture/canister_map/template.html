How to read this map

Every box is a type of canister (smart contract) that OpenChat runs on the Internet Computer, grouped by what it does. An arrow from one canister to another means the first makes calls to the second. Click any canister to zoom in on its endpoints, state, background jobs and the calls it makes and receives.

Everything shown is read from the source code: endpoints from the #[query] and #[update] functions, state from each canister's Data struct, calls from the canister-to-canister clients used. Descriptions and live counts are the only parts written or fetched by hand.
